# Gestor de Tareas

Aplicación Android desarrollada para el Ejercicio de feedback 1 de la asignatura *Programación dirigida por eventos* (Grado en Ingeniería Informática, UAX).

**Autora:** Vanessa Mouriz

## Requisitos técnicos

- Lenguaje: Java
- SDK mínimo: API 24 (Android 7.0)
- Base de datos: SQLite (mediante `SQLiteOpenHelper`)
